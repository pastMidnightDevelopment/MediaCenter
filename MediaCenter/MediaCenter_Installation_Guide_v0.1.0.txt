MediaCenter Installation Guide
Version 0.1.0 - Foundation Build

Purpose
-------
This guide explains how to install and launch the Raspberry Pi MediaCenter project.

The MediaCenter is designed as a family-friendly Raspberry Pi dashboard for:
- Streaming
- Gaming
- Security
- Utilities
- Settings

Current design choice:
- Autostart is disabled for now.
- MediaCenter launches from a clickable desktop icon.
- YouTube Music is included under Streaming, not as a separate Music menu.

---------------

First-Time Setup
----------------
Open a terminal and run:

cd ~/MediaCenter

Then make the installer executable:

chmod +x ~/MediaCenter/Installer/install.sh

Run the installer:

~/MediaCenter/Installer/install.sh


Install Required Packages
-------------------------
Run:

chmod +x ~/MediaCenter/Installer/requirements.sh
~/MediaCenter/Installer/requirements.sh

This installs core tools, streaming tools, controller tools, Bluetooth tools, monitoring tools, and attempts optional gaming installs.

Some optional packages may fail depending on Raspberry Pi OS version. That is okay for now.


Create Desktop Launcher
-----------------------
Run:

chmod +x ~/MediaCenter/Installer/desktop_launcher.sh
~/MediaCenter/Installer/desktop_launcher.sh

This creates a clickable MediaCenter icon on the desktop.

On Raspberry Pi OS Bookworm, you may need to right-click the icon and choose:

Trust this executable

or:

Allow Launching


Launch MediaCenter
------------------
Use the desktop icon, or run manually:

~/MediaCenter/dashboard.sh


Autostart Status
----------------
Autostart is intentionally disabled for now.

The autostart script is saved for later here:

~/MediaCenter/Installer/autostart.sh

Do not run it yet unless you want MediaCenter to open automatically after desktop login.

If an old autostart desktop file exists, move it out of autostart:

mkdir -p ~/MediaCenter/Disabled
mv ~/.config/autostart/mediacenter.desktop ~/MediaCenter/Disabled/mediacenter-autostart.desktop

Gaming Testing
--------------
Check installed gaming apps:

which steamlink
which moonlight-qt
which retroarch

Steam Link requirements:
- Gaming PC is powered on
- Steam is running on gaming PC
- Remote Play is enabled in Steam
- Raspberry Pi and gaming PC are on the same network

Best network setup:
- Gaming PC on Ethernet
- Raspberry Pi on Ethernet or strong 5 GHz Wi-Fi


Controller Testing
------------------
Mini keyboard/touchpad:
- Should usually work immediately.

PS4 controller:
- Test first over USB.
- Later test Bluetooth pairing.
- Use Controller Status and Device Manager to confirm detection.

PS3 controller:
- Planned for later.
- May require extra setup.

Retro USB controllers:
- Usually plug-and-play.
- RetroArch may need button mapping.
